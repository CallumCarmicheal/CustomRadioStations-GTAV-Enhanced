Enhanced build dependencies
===========================

Required to COMPILE (manual):
  ScriptHookVDotNet3.dll  - from the SAME ScriptHookVDotNet Enhanced release installed in GTA V

Restored automatically from NuGet:
  JAJ.Packages.MiniAudioEx 3.3.6 (MIT)

The build stages these MiniAudioEx files automatically:
  MiniAudioExNET.dll       - managed .NET Standard 2.0 wrapper
  miniaudioex.dll          - Windows x64 native runtime

irrKlang, irrKlang.dll, ikpMP3.dll and ikpFlac.dll are no longer used.
